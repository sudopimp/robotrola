
# Manufacturing checklist

- [ ] Confirm jurisdiction and legal review.
- [ ] Select target build: bench, upper-body stand, or full-body research rig.
- [ ] Print calibration cube and insert test.
- [ ] Print non-load shell only.
- [ ] Build safety MCU before actuator power.
- [ ] Validate wiring harness continuity.
- [ ] Validate e-stop with dummy load.
- [ ] Validate one actuator fixture.
- [ ] Build camera calibration rig.
- [ ] Produce BOM costed order.
- [ ] Record serial numbers and firmware versions.
- [ ] Generate calibration hash.
- [ ] Run `python scripts/validate_repo.py`.
