# Build 02 — Fixed upper-body stand

Goal: validate head/torso/one-arm integration without biped risks.

## Included subsystems

- torso shell and electronics tray
- head camera bar
- neck gimbal
- one shoulder/elbow/wrist chain
- safety MCU and e-stop
- RGB-D perception
- local voice stack placeholder

## Excluded

- biped locomotion
- autonomous whole-body motion
- human-contact operation
- cloud control
