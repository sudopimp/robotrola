
# Beverage service module

Status: disabled by default.

This is a food-grade, non-explicit service module for controlled beverage dispensing. Use only food-grade tubing, a low-voltage peristaltic pump, leak detection, and manual confirmation.

Safety requirements:

- isolated from electronics
- no pressurized vessel
- no hot liquids
- pump current monitoring
- leak sensor under reservoir and tube path
- cleaning routine after use
- manual confirm before dispense
