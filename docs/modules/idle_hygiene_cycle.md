
# Idle hygiene cycle module

Status: disabled by default.

The hygiene cycle is modeled as an external sealed dock, not as an exposed body feature.

Requirements before enabling:

- robot is docked and motion locked
- no person/pet detected near dock
- sealed enclosure confirmed
- UV-C interlock confirmed if UV-C is installed
- airflow/temperature within range
- removable liner present
- leak and condensation sensors clear

Do not activate UV-C outside a sealed, interlocked enclosure.
