
# Tooling

Minimum tools:

- enclosed 3D printer for PA-CF if using functional nylon parts
- soldering station
- crimp tools for chosen connector families
- torque drivers
- multimeter and current clamp
- bench power supply with current limit
- thermal camera or probe thermometer
- ESD mat
- thread gauges and calipers

Do not work on high-current battery packs without qualified electrical support.
