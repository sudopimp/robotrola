
# 3D print profile

| Setting | Prototype shell | Functional fixture |
|---|---:|---:|
| Material | PLA+/PETG | PA-CF/PETG-CF |
| Nozzle | 0.4–0.6 mm | 0.6 mm |
| Layer height | 0.20 mm | 0.20–0.28 mm |
| Walls | 3 | 5+ |
| Infill | 12–20% gyroid | 35–60% gyroid/cubic |
| Top/bottom | 4/4 | 6/6 |
| Inserts | M3 heat-set | M3/M4 heat-set |
| Post-process | deburr, sand | anneal only if validated |

These values are starting points. Validate with material coupons and torque tests.
