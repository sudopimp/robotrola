
# Skin and soft materials

This repo includes only non-explicit shell and skin research notes.

Material candidates:

- platinum-cure silicone for external soft skin research
- thermoplastic elastomer for removable pads
- washable fabric covers for early prototypes
- pressure/tactile sensor layers under removable surfaces

Requirements:

- removable and cleanable
- biocompatibility documentation from vendor
- no hidden fluid retention zones
- no inaccessible mold growth cavities
- no electronics embedded without service path
