
# Simulation

## Gazebo

Use Gazebo for fast open simulation, ROS 2 bridges, sensors, and controller smoke tests.

## Isaac Sim / Isaac Lab

Use Isaac workflows for high-fidelity digital twin, synthetic data, GPU training, and sim-to-real experiments. Keep it optional because hardware contributors may not have GPU workstations.

## Digital twin checklist

- match mesh scale
- measure mass/inertia
- measure joint limits
- measure actuator delay
- model foot contact/friction
- compare simulated and real sensor timings
