
# Teleoperation

Teleop is for data collection and supervised validation, not entertainment.

Allowed initially:

- keyboard low-speed joint jog
- gamepad guarded pose targets
- web UI status/control with local network only
- LeRobot data collection episodes

Not allowed initially:

- autonomous biped locomotion near people
- AI direct actuator commands
- cloud remote teleoperation
- high-speed gestures
